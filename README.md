# Rendera

Virtuella 3D-visningar av bostäder.

## Kolla på hemsidan

Gå till: **[rendera.vercel.app](https://rendera.vercel.app)**

## Lägga till en visning

Öppna `app/lib/visningar.ts` och lägg till ett objekt med titel, beskrivning och Matterport-länk. Den första i listan visas stort på startsidan, alla visas under `/visningar`.

## Kör lokalt

```bash
git clone git@github.com:Ibrahim-giti/rendera.git
cd rendera
npm install
npm run dev
```

Öppna [http://localhost:3000](http://localhost:3000) i webbläsaren. Inga miljövariabler behövs.
