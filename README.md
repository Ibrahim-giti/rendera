# Rendera

Virtuella 3D-visningar av svenska bostäder.

## Kolla på hemsidan

Gå till: **[rendera.vercel.app](https://rendera.vercel.app)**

## Kör lokalt

Klona projektet:
```bash
git clone git@github.com:Ibrahim-giti/rendera.git
cd rendera
```

Installera dependencies:
```bash
npm install
```
